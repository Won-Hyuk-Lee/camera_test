# 카메라 테스트

Android에서 화면 잠금과 전화 수신이 동영상 녹화에 미치는 영향을 확인하는 학습용 앱입니다.

일반 촬영과 빠른 녹화(위젯)는 각각 전면·후면 설정을 저장합니다. 파일당 길이는 **한 파일을 나누는 간격**이며 전체 종료 조건과 별개입니다. 예를 들어 파일당 30분과 직접 중지를 선택하면 30분에서 다음 파일로 넘어가고, 직접 중지할 때까지 이어집니다.

## 저장 영상에서 화면만 멈출 때

1. 비공개 보관함에서 원본을 유지한 채 **⋮ → 영상 시간정보 검사**를 실행합니다. 검사 결과의 가장 긴 영상 간격과 그 시작·끝 시각을 확인합니다. 이전 검사에 위치가 없으면 다시 검사합니다.
2. 원본을 공개 갤러리로 내보낸 뒤 보관함과 다른 재생기에서 **같은 시각**을 비교합니다. 시간정보 검사는 압축된 영상 샘플의 시각을 검사합니다. 정상 시각으로 같은 그림을 반복 저장한 경우나 재생기 문제까지 판정하지는 않습니다.
3. **권한 및 설정 센터 → 촬영 결과 및 진단 기록 → 진단 기록 내보내기**에서 해당 세션을 확인합니다. 촬영 당시의 저장 결과, 현재 원본 존재 여부, 카메라·음성 상태가 별도로 기록됩니다. 음성 트랙이 있다는 것만으로 실제 소리가 녹음됐다고 판단할 수는 없습니다.

실기기에서 비교할 때는 같은 설정으로 움직이는 피사체와 소리를 짧게 촬영합니다. 화면 잠금만 한 경우와, 잠근 뒤 전화를 받지 않고 부재중으로 넘긴 경우의 원본을 비교하면 수신 전후 차이를 찾을 수 있습니다.

## 디버그 빌드

Windows에서 저장소 루트의 `gradlew.bat :app:assembleDebug :app:testDebugUnitTest`를 실행합니다. 설치 파일은 `app/build/outputs/apk/debug/app-debug.apk`입니다.
